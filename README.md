## How to use

1. Open the [program collection](TurboC_Programs/).
2. Choose a program from the table above and inspect its source.
3. Run it in the intended Turbo C / Turbo C++ learning environment.
4. For modern GCC/Clang, review legacy headers, console functions, and compiler-specific code before attempting to build.

> **Scope:** This is a collection of educational legacy C exercises, not a modern portable C library. No program output is represented as tested in this documentation update.
